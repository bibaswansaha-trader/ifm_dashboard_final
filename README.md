# ifm_dashboard_final
Interactive International Financial Management (IFM) Streamlit dashboard for USD/INR analysing Relative Purchasing Power Parity (PPP) &amp; Currency Misalignment, Interest Rate Parity (IRP) &amp; Uncovered Carry Trade Profitability, International Fisher Effect (IFE) regression diagnostics, and Political Risk, Country Risk &amp; Portfolio Diversification.
